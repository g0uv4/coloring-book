# Intensity — simple / medium / advanced

Open-Line Plate has **one line language** and **three intensities**. Intensity is **which photo parts you keep**, not how dense the ink is. Never invent a fourth style (watercolor, manga screentone, mandala, photoreal ink).

Pick **one** intensity per photo. Default is **medium** unless the user names another.

| User says | Intensity | Alias |
|---|---|---|
| 簡單、幼兒、小孩、少一點線、simple, easy, kids | `simple` | 低 |
| （沒指定）、中等、普通、家庭、medium, default | `medium` | 中 |
| 高階、進階、更多細節、細一點、更多元件、advanced, detailed | `advanced` | 高 |

If they ask for all three, generate three plates of the **same photo**, same crop, same identity facts, then three A4 pages (or one PDF with three pages). Label each page.

## Shared law (all three)

- Black outlines, paper-white interiors
- **Closed, continuous** colorable regions — no broken, dashed, or fading strokes
- One even **medium-thick** felt-tip weight (simple may be a bit thicker; advanced is **not** thinner)
- Cartoon translation of the real photo, not a filter
- No gray, hatching, stipple, zentangle, or photoreal pores
- Faces never become stick figures and never become traced photographs
- Identity facts survive (count, pose, glasses, clothes, distinctive props)
- If a line would break because it is too fine, **do not draw it**

## What changes

Advanced ≠ more lines. Advanced = **more named components from the photograph** still drawn with the same clean closed outlines.

| | simple | medium | advanced |
|---|---|---|---|
| Who it's for | about ages 4–7 | about ages 8–14 (default) | teens / casual adult coloring |
| Line weight | slightly thicker | medium felt-tip | **same as medium** (do not go hairline) |
| What you keep | the 3–6 largest subjects | main subjects + a few inner facts | **every distinctive named part** in the photo that can be a closed shape |
| What you drop | secondary objects, inner seams | fingernail-sized texture | only parts too small to close as a loop |
| Face | oval, eyes, brows, U-nose, smile; 3–5 hair clumps | full portrait recipe; 4–8 hair clumps | same recipe + **photo accessories** (glasses temples, earrings as loops, a visible pocket). Still no lashes/pores/wrinkles/strand hair |
| Clothes | 1 silhouette per garment | 1–3 blocks, 2–5 stripes if striped | extra **garments and props that are in the photo** (collar, bag, watch as a circle). Not extra fashion seams you invent |
| Scene | big silhouettes only | main structure | each real machine/building **part** that a viewer would name (mast, gantry arm, tail, window band) as its own closed shape |
| Effects (fire, smoke, water) | 1–2 big blobs | simple inner/outer | **photo-accurate silhouette** of the effect — not cartoon clip-art fire / sparkles |
| Forbidden even here | mandala, hair strands, brick-by-brick, broken lines | same | same — **never** denser hatch just to look “detailed” |

## Scene example (space shuttle launch)

Use this as the calibration memory, not as a subject to copy onto other photos.

- **simple:** orbiter + tank + two boosters as clean tubes, tower as stacked platforms, two exhaust columns, a few smoke blobs, empty sky.
- **medium:** tank with a couple of rings, booster segment seams, cockpit window band, wing leading edges, tower platforms + simple lattice, two exhaust columns, smoke lobes, a couple of clouds.
- **advanced:** same line weight as medium, plus **parts the photo actually has**: lightning mast, gantry / access arms, elevator shaft, OMS pods, body flap, vertical tail, payload-bay center seam, SRB nose cones and attach struts, tank ogive, sky clouds. Exhaust stays two tall **rocket plumes** (inner core + outer envelope) like the photo — never cartoon campfire tongues or spark teardrops. Skip pipe-spaghetti and tile-by-tile panels if those lines would break.

## Regeneration

If the plate is the wrong intensity:

- Too empty when user asked advanced → add **missing named objects** from the inventory as closed shapes; do **not** add extra hatch, ribs, or thinner lines.
- Lines broken / dashed / hairline → redraw with fewer shapes and thicker continuous outlines; drop anything you cannot close.
- Cartoon clip-art fire / sparkles when the photo shows real exhaust, lamps, etc. → match the photo’s silhouette of the effect.
- Too busy when user asked simple → keep only the largest silhouettes.
- Gray or photoreal at any intensity → "pure white interiors, no gray" retry once.
