# Style memory — coordinator writes, user never invokes it

Open-Line Plate is the house style. User memory stores defaults on top of it. Never store the photograph, faces, or third-party coloring pages.

## Who writes

The **coloring-book coordinator** writes memory. The user must **never** be told to type `/memory-with-docs`.

After a successful write, one short line with **no tool name**: `已記住你的著色本設定。`

## Layer A — standing locks

House locks after first QC SHIP: closed continuous lines, white interiors, smooth ink, no cartoon fire, textures as slabs, preview then PDF.

## Layer B — default intensity

Write when they say `以後都用高階` / `記住這個風格`. Do **not** write default intensity on `輸出 PDF` alone.
